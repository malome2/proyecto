Actúa como tutor experto en Desarrollo de Aplicaciones Web (DAW) y arquitectura web.

Estoy desarrollando mi proyecto final de DAW. El proyecto es un MUSEO VIRTUAL DE VIDEOJUEGOS en una aplicación web.

DESCRIPCIÓN GENERAL:
- Es una web con varias secciones: Inicio, Quiénes somos, Museo (juego), Login/Registro, Recomendaciones y Panel Administrador.
- El “Museo” es una experiencia interactiva en primera persona estilo Doom clásico (2.5D), implementada en JavaScript usando Canvas y raycasting simple.
- El usuario se mueve con WASD por un pasillo sencillo con cuadros en las paredes.
- Cada cuadro representa un videojuego.
- Al acercarse a un cuadro aparece información del juego, su imagen, un vídeo de gameplay y suena su música.

FUNCIONALIDADES:
- Gestión de usuarios con autenticación.
- Roles: USER y ADMIN.
- Usuarios normales pueden:
  - Registrarse y hacer login
  - Visitar el museo
  - Enviar recomendaciones de videojuegos para el museo
- Administradores pueden:
  - Añadir, editar y eliminar juegos (cuadros) del museo
  - Subir imágenes, música y vídeos
  - Aprobar recomendaciones de usuarios
- Todo el contenido del museo se carga dinámicamente desde base de datos.

TECNOLOGÍAS DEFINIDAS (NO CAMBIAR):
- Frontend: HTML5, CSS3, JavaScript Vanilla, Canvas, Fetch API
- Backend: Node.js + Express
- Autenticación: JWT
- Base de datos: MySQL / MariaDB
- Subida de archivos: Multer
- Hosting: Frontend (Netlify/Vercel), Backend (Render/Railway), BBDD en la nube

BASE DE DATOS (RESUMEN):
- usuarios(id, username, email, password_hash, role, created_at)
- juegos(id, titulo, descripcion, imagen_cuadro, imagen_juego, video_url, musica_url, pos_x, pos_y, creado_por)
- recomendaciones(id, titulo, descripcion, usuario_id, estado)

RESTRICCIONES IMPORTANTES:
- Proyecto pensado para hacerse mayoritariamente en horas de clase (6h/semana).
- El museo debe ser simple: un solo mapa, sin enemigos ni físicas complejas.
- Prioridad absoluta: funcionalidad, base de datos, roles y API REST.
- El componente “juego” es un extra visual, no el núcleo del proyecto.
